Overview

OnPremises Service is a web service to manage the on-prem clusters and control planes.

Version information

Version : 0.9.165 (BETA)

License information

License : Apache 2.0
Terms of service : https://www.cloudera.com/legal/commercial-terms-and-conditions.html

URI scheme

Schemes : HTTPS

Consumes

  • application/json

Produces

  • application/json
