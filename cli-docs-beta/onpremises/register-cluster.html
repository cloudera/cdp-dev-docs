register-cluster¶

subtitle

Register an existing cluster

version

0.9.165-dirty

Description¶

Register an existing cluster as an on-premise cluster.

Synopsis¶

  register-cluster
--datacenter-name <value>
--manager-uri <value>
[--username <value>]
[--password <value>]
[--name <value>]
[--location-id <value>]
[--tags <value>]
[--description <value>]
[--environment-crn <value>]
[--cli-input-json <value>]
[--generate-cli-skeleton]

Options¶

--datacenter-name (string)

The data center name of the registered on-premise cluster.

--manager-uri (string)

The manager URI of the on-premise cluster.

--username (string)

The user name for the cluster.

--password (string)

The password for the cluster.

--name (string)

Name of the cluster. Should match the name it uses in Cloudera Manager (or Ambari).

--location-id (integer)

The location of the cluster.

--tags (array)

Tags associated with the registration

Syntax:

"string" "string" ...

--description (string)

Description of the onpremises cluster

--environment-crn (string)

The CRN of the Private Cloud environment.

--cli-input-json (string)

Performs service operation based on the JSON string provided. The JSON string follows the format provided by --generate-cli-skeleton. If other arguments are provided on the command line, the CLI values will override the JSON-provided values.

--generate-cli-skeleton (boolean)

Prints a sample input JSON to standard output. Note the specified operation is not run if this argument is specified. The sample input can be used as an argument for --cli-input-json.

Output¶

clusterCrn -> (string)

The CRN of registered on-premise cluster.

Form Factors¶

public, private
