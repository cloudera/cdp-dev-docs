list-cluster-services¶

subtitle

List service details of a cluster.

version

0.9.165-dirty

Description¶

Gets the service details of a cluster.

Synopsis¶

  list-cluster-services
--cluster-crn <value>
[--cluster-name <value>]
[--manager-uri <value>]
[--username <value>]
[--password <value>]
[--cli-input-json <value>]
[--generate-cli-skeleton]

Options¶

--cluster-crn (string)

CRN of the registered on-premise cluster.

--cluster-name (string)

Name of the cluster in the cloudera-manager.

--manager-uri (string)

CRN of the registered on-premise cluster.

--username (string)

Username of the cloudera-manager.

--password (string)

Password of the cloudera-manager.

--cli-input-json (string)

Performs service operation based on the JSON string provided. The JSON string follows the format provided by --generate-cli-skeleton. If other arguments are provided on the command line, the CLI values will override the JSON-provided values.

--generate-cli-skeleton (boolean)

Prints a sample input JSON to standard output. Note the specified operation is not run if this argument is specified. The sample input can be used as an argument for --cli-input-json.

Output¶

services -> (array)

List of service detail information.

item -> (object)

Object containing the service information.

Form Factors: public, private

name -> (string)

Name of the service.

version -> (string)

Version of the service.

state -> (string)

State of the service.

serviceUrl -> (string)

URL of the service in Cloudera Manager.

Form Factors¶

public
