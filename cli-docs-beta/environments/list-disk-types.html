list-disk-types¶

subtitle

Returns the available disk types for all cloud platforms.

version

0.9.165-dirty

Description¶

Returns the available disk types, default disks, disk mappings, and display names for all supported cloud platforms.

Synopsis¶

  list-disk-types
[--cli-input-json <value>]
[--generate-cli-skeleton]

Options¶

--cli-input-json (string)

Performs service operation based on the JSON string provided. The JSON string follows the format provided by --generate-cli-skeleton. If other arguments are provided on the command line, the CLI values will override the JSON-provided values.

--generate-cli-skeleton (boolean)

Prints a sample input JSON to standard output. Note the specified operation is not run if this argument is specified. The sample input can be used as an argument for --cli-input-json.

Output¶

platformDiskTypes -> (array)

List of disk type information per cloud platform.

item -> (object)

Disk type information for a single cloud platform.

platform -> (string)

The cloud platform name (e.g. AWS, AZURE, GCP).

diskTypes -> (array)

The list of supported disk type names for this platform.

item -> (string)

defaultDiskType -> (string)

The default disk type name for this platform.

diskMappings -> (map)

Mapping of disk type name to volume parameter type for this platform.

key -> (string)

value -> (string)

displayNames -> (map)

Mapping of disk type name to its display name for this platform.

key -> (string)

value -> (string)

Form Factors¶

public, private
