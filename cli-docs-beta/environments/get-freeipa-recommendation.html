get-freeipa-recommendation¶

subtitle

Gets a recommendation of cloud resources for a FreeIPA.

version

0.9.165-dirty

Description¶

Returns VM type recommendations for FreeIPA based on credential, region, and optional availability zone and architecture.

Synopsis¶

  get-freeipa-recommendation
--credential <value>
--region <value>
[--availability-zone <value>]
[--architecture <value>]
[--cli-input-json <value>]
[--generate-cli-skeleton]

Options¶

--credential (string)

The name or CRN of the credential.

--region (string)

The region for the recommendation.

--availability-zone (string)

The availability zone for the recommendation.

--architecture (string)

The architecture for the recommendation (e.g., x86_64).

--cli-input-json (string)

Performs service operation based on the JSON string provided. The JSON string follows the format provided by --generate-cli-skeleton. If other arguments are provided on the command line, the CLI values will override the JSON-provided values.

--generate-cli-skeleton (boolean)

Prints a sample input JSON to standard output. Note the specified operation is not run if this argument is specified. The sample input can be used as an argument for --cli-input-json.
