list-vm-types-for-environment¶

subtitle

Lists the available VM types for an environment.

version

0.9.165-dirty

Description¶

Lists the virtual machine types available within an existing environment.

Synopsis¶

  list-vm-types-for-environment
--environment-crn <value>
[--instance-type <value>]
[--resource-type <value>]
[--availability-zones <value>]
[--architecture <value>]
[--cli-input-json <value>]
[--generate-cli-skeleton]

Options¶

--environment-crn (string)

The CRN of the environment.

--instance-type (string)

The current instance type to find upgrade targets for.

--resource-type (string)

The resource type to filter by.

--availability-zones (array)

The availability zones to consider.

Syntax:

"string" "string" ...

--architecture (string)

The CPU architecture to filter by.

--cli-input-json (string)

Performs service operation based on the JSON string provided. The JSON string follows the format provided by --generate-cli-skeleton. If other arguments are provided on the command line, the CLI values will override the JSON-provided values.

--generate-cli-skeleton (boolean)

Prints a sample input JSON to standard output. Note the specified operation is not run if this argument is specified. The sample input can be used as an argument for --cli-input-json.
